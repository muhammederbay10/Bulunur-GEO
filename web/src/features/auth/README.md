# Auth Feature

The Supabase starter kit auth screens and forms are intentionally preserved for Phase 1.

Current working routes:

- `/auth/login`
- `/auth/sign-up`
- `/auth/confirm`
- `/auth/forgot-password`
- `/auth/update-password`

Phase 1 should modify these existing flows instead of rebuilding auth from scratch.
The preserved starter-kit components live in `src/features/auth/components`.
